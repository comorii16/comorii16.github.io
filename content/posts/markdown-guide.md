이 글은 `.md` 확장자로 작성했습니다. `.mdx`와 마찬가지로 그대로 렌더링됩니다.
차이는 하나뿐입니다. `.md`에서는 React 컴포넌트를 쓸 수 없습니다.

## 제목

`#` 부터 `####` 까지 사용합니다. 본문에서는 `##` 부터 시작하는 편이 좋습니다.
글 제목은 front matter의 `title`이 `h1`으로 렌더링되기 때문입니다.

## 강조

**굵게**, *기울임*, ~~취소선~~, `인라인 코드` 를 사용할 수 있습니다.

## 목록

- 순서 없는 목록
- 두 번째 항목

1. 순서 있는 목록
2. 두 번째 항목

- [x] 체크된 항목
- [ ] 체크되지 않은 항목

## 인용

> 인용문입니다.
>
> 문단을 나눌 수도 있습니다.

## 코드

언어를 지정하면 해당 언어로 하이라이팅됩니다.

```bash
pnpm install
pnpm dev
```

```json
{
  "name": "my-blog",
  "private": true
}
```

언어를 지정하지 않으면 하이라이팅 없이 그대로 나옵니다.

```
plain text
```

## 표

| 문법 | 결과 |
| --- | --- |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `` `code` `` | `code` |

## 이미지

`public/` 아래 경로를 그대로 적습니다.

```markdown
![설명](/images/posts/글-slug/파일명.webp)
```

`alt` 텍스트는 접근성을 위해 꼭 채워주세요.

## 링크

[외부 링크](https://developer.mozilla.org)와 [내부 링크](/posts/)를 모두 쓸 수 있습니다.
내부 링크는 자동으로 클라이언트 라우팅으로 처리됩니다.
